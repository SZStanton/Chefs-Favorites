# Chef's Favorites

A non-React web app where users submit a main ingredient and receive a chef-picked dish suggestion, with order tracking. This project demonstrates working with an external API (TheMealDB) to fetch and display real recipe data using vanilla HTML, CSS, and JavaScript.

## Features

- Enter a main ingredient and receive a suggested dish
- Pulls real recipe data from the TheMealDB API
- Pending orders list with order completion tracking
- Clean, styled interface (no framework — vanilla HTML/CSS/JS)

## Tech Stack

HTML5, CSS3, JavaScript, TheMealDB API

## Installation

1. Clone the repository

   ```bash
   git clone https://github.com/SZStanton/Chefs-Favorites
   ```

2. Open `index.html` in your browser — no build step or dependencies required
